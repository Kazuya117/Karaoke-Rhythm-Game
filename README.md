# 顔ノーツ☆カラオケバトル

仲間の顔写真がノーツになって流れてくる、カラオケ向けのリズムゲームです。
スマホ1台を回して順番にプレイし、最後に顔写真つきで結果発表します。

## 3つのモード

| モード | 内容 |
| --- | --- |
| **曲をえらぶ（30秒）** | 好きな曲を検索して、その曲を鳴らしながら遊びます。テンポも譜面も自動で作られます（通信が必要）。 |
| **内蔵ビート** | ゲームが演奏するオリジナル曲（3曲）で遊びます。通信不要。 |
| **カラオケに合わせる** | カラオケ機で流れている曲のビートをタップしてテンポを測り、その曲に合わせて遊びます（歌う人の横でタンバリン係）。 |

「曲をえらぶ」は Apple の試聴用30秒音源を使います。曲は Apple から直接受け取って再生するだけで、
ダウンロードも保存もしません。「全員おなじ曲」と「1人ずつえらぶ」を選べます。

## あそびかた

1. 「あそぶ」→ メンバーの名前と顔写真を登録（写真はなくてもOK）
2. モードとむずかしさをえらぶ
3. 流れてくる顔が下の丸に重なった瞬間に、そのレーンをタップ！
   - 10コンボでサングラス😎、25コンボで王冠👑、50コンボで虹色リング
   - ミスが続くと泣き顔に…
   - サビ（フィーバー）では全員の顔が流れてきます
4. 全員が終わったら、表彰台で結果発表

パソコンでは `D` `F` `J` `K` キーでも遊べます。

## みんなでランキング（各自のスマホで遊ぶ）

同じ時間に集まらなくても、7人がそれぞれ自分のスマホで遊んで順位を競えます。

1. 幹事がタイトルの「みんなでランキング」→ 曲とむずかしさを決めます
2. 「メンバーをみんなに配る」を押してから、「お題リンクをコピー」して LINE などに貼って配ります
3. 各自が**お題リンク**を開き、「あなたは誰？」から自分をえらんでプレイします
4. スコアは自動で集まり、全員の画面に顔写真つきのランキングが出ます

参加者はかならず**お題リンク**から入ってください。ゲームのURLを直接開いてもメンバーは入りません。
メンバーが端末に届くのは、お題リンクを開いたときだけです。

お題の中身（曲・むずかしさ）はスプレッドシートに置くので、配るリンクは
`https://.../#e=<ID>&r=<お題ID>` という短い形になります。

同じ曲なら**全員まったく同じ譜面**になるので、そのまま勝負になります。
何度でも挑戦でき、いちばん良いスコアだけが残ります。
電波が悪くて送れなかったときは端末に取っておき、次に開いたときに自動で送り直します。

### メンバーを配る

幹事の端末にメンバーを登録して「メンバーをみんなに配る」を押すと、名前と小さな似顔絵が
スプレッドシートに入ります。以後、お題リンクを開いた人の端末には**自動で7人が入る**ので、
各自は「あなたは誰？」から自分をえらぶだけです。

メンバーをまとめて用意したいときは、メンバー画面の「ファイルからまとめて読み込む」から
次の形のJSONファイルを読み込めます。

```json
{ "members": [ { "name": "なまえ", "avatar": "data:image/jpeg;base64,..." } ] }
```

似顔絵はこのリポジトリには入りません。幹事のスプレッドシートと、リンクを開いた仲間の端末にだけ入ります。

### 準備（幹事が初回だけ・10分）

1. Googleドライブで新しい**スプレッドシート**を作ります
2. メニューの「拡張機能」→「Apps Script」を開きます
3. [`server/code.gs`](server/code.gs) の中身を全部貼り付けて保存します
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類は**ウェブアプリ**
5. 「次のユーザーとして実行」は**自分**、「アクセスできるユーザー」は**全員**にします
6. 出てきた `https://script.google.com/macros/s/.../exec` を、ゲームの「集計用のURL」に貼ります
7. 「接続をテスト」を押して、スプレッドシートに「テスト」の行ができれば成功です
8. エディタ上部の関数一覧で `authorize` を選んで「実行」を1回押し、外部サイトへの接続を許可します
   （曲の検索を中継するために必要です。押さないと「中継=…権限がありません」と出ます）

### うまくいかないとき

| 画面の表示 | 原因と直し方 |
| --- | --- |
| 集計用のコードが古いままです | `server/code.gs` を貼り直し、「デプロイを管理」→ 編集 → バージョンを「新バージョン」にして再デプロイ |
| お題が登録されていません | 幹事の端末で「ランキング更新」を押すと登録し直します（リンクはそのまま使えます） |
| このお題は見つかりませんでした | 幹事がまだお題を登録できていません。幹事に上の操作をお願いしてください |
| 検索できませんでした | 下に出る「つながりを調べる」を押すと、どこで止まっているか分かります |
| LINEなどアプリ内のブラウザ | Apple への通信が遮断されることがあります。検索は集計用URLが中継しますが、音源は届かないことがあるので、Safari で開き直してください |
| 古い画面のまま直らない | タイトル画面の下に出る `ver` を確認してください。最新でなければ、ブラウザのキャッシュを消して開き直します |

このURLを知っている人は誰でも書き込めるので、仲間内だけで共有してください。
スコアはすべて自分のスプレッドシートに入るので、あとから見返せます。

### 古いキャッシュが残ってしまったら

スマホのブラウザが古い `index.html` を握っていると、更新が届きません。
そのときは URL の末尾に目印を付けて配ります。別のページとして扱われるので、確実に新しく読み込まれます。

```
https://kazuya117.github.io/Karaoke-Rhythm-Game/?v=2
```

この目印はお題リンクにも引き継がれるので、受け取った人も新しい版で開きます。
タイトル画面と「曲をえらぶ」画面の下に出る `ver` で、いま動いている版を確認できます。

### 別のグループでも遊ぶ

URL に `?g=<好きな名前>` を付けると、**別のグループ**になります。

```
https://kazuya117.github.io/Karaoke-Rhythm-Game/        ← グループ1
https://kazuya117.github.io/Karaoke-Rhythm-Game/?g=b    ← グループ2
```

端末に保存されるメンバーも、スプレッドシートの `members` シートも、グループごとに分かれます。
スプレッドシートと Apps Script は**1つのまま**で大丈夫です。お題リンクにもグループが引き継がれます。

集計用のURLは**どのグループでも同じもの**を使います。2つ目以降のグループでは、
同じ端末のほかのグループで使っているURLを自動で入れるので、そのまま進めます。

## 写真とプライバシー

- 顔写真はブラウザの localStorage（その端末の中）にだけ保存され、どこにも送信されません。
  このリポジトリにも写真は含まれません。
- 「曲をえらぶ」で検索した言葉は、Apple の検索サービスに送られます。
- 「みんなでランキング」で遊ぶときだけ、名前・スコア・小さな顔写真（96px）が
  幹事のスプレッドシートに送られます。ほかの写真は端末から出ません。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面とスタイル |
| `game.js` | ゲーム本体 |
| `beat.js` | 曲の解析（テンポ検出と譜面の自動生成） |
| `server/code.gs` | みんなでランキングの受け口（Google Apps Script） |

`beat.js` は音の立ち上がり（スペクトルフラックス）を4つの帯域で調べ、
自己相関とくし形フィルタでテンポを推定したあと、最小二乗法で拍の格子を引き直します。
低い音は左のレーン、高い音は右のレーンに割り当てます。

内蔵ビートの音は WebAudio の合成音で作っていて、音源ファイルは使っていません。
