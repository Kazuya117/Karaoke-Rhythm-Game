# 顔ノーツ☆カラオケバトル

仲間の顔写真がノーツになって流れてくる、カラオケ向けのリズムゲームです。
スマホ1台を回して順番にプレイし、最後に顔写真つきで結果発表します。

## 3つのモード

| モード | 内容 |
| --- | --- |
| **曲をえらぶ（30秒）** | 好きな曲を検索して、その曲を鳴らしながら遊びます。テンポも譜面も自動で作られます（通信が必要）。 |
| **内蔵ビート** | ゲームが演奏するオリジナル曲（3曲）で遊びます。通信不要。 |
| **カラオケに合わせる** | カラオケ機で流れている曲のビートをタップしてテンポを測り、その曲に合わせて遊びます（歌う人の横でタンバリン係）。 |

「曲をえらぶ」は Apple の試聴用30秒音源を使います。曲は Apple から直接受け取って再生するだけで、
ダウンロードも保存もしません。「全員おなじ曲」と「1人ずつえらぶ」を選べます。

## あそびかた

1. 「あそぶ」→ メンバーの名前と顔写真を登録（写真はなくてもOK）
2. モードとむずかしさをえらぶ
3. 流れてくる顔が下の丸に重なった瞬間に、そのレーンをタップ！
   - 10コンボでサングラス😎、25コンボで王冠👑、50コンボで虹色リング
   - ミスが続くと泣き顔に…
   - サビ（フィーバー）では全員の顔が流れてきます
4. 全員が終わったら、表彰台で結果発表

パソコンでは `D` `F` `J` `K` キーでも遊べます。

## みんなでランキング（各自のスマホで遊ぶ）

同じ時間に集まらなくても、7人がそれぞれ自分のスマホで遊んで順位を競えます。

1. 幹事がタイトルの「みんなでランキング」→ 曲とむずかしさを決めます
2. 「お題リンクをコピー」して、LINEなどに貼って配ります
3. 各自がリンクを開き、名前と顔写真を登録してプレイします
4. スコアは自動で集まり、全員の画面に顔写真つきのランキングが出ます

同じ曲なら**全員まったく同じ譜面**になるので、そのまま勝負になります。
何度でも挑戦でき、いちばん良いスコアだけが残ります。
電波が悪くて送れなかったときは端末に取っておき、次に開いたときに自動で送り直します。

### 準備（幹事が初回だけ・10分）

1. Googleドライブで新しい**スプレッドシート**を作ります
2. メニューの「拡張機能」→「Apps Script」を開きます
3. [`server/code.gs`](server/code.gs) の中身を全部貼り付けて保存します
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類は**ウェブアプリ**
5. 「次のユーザーとして実行」は**自分**、「アクセスできるユーザー」は**全員**にします
6. 出てきた `https://script.google.com/macros/s/.../exec` を、ゲームの「集計用のURL」に貼ります
7. 「接続をテスト」を押して、スプレッドシートに「テスト」の行ができれば成功です

このURLを知っている人は誰でも書き込めるので、仲間内だけで共有してください。
スコアはすべて自分のスプレッドシートに入るので、あとから見返せます。

## 写真とプライバシー

- 顔写真はブラウザの localStorage（その端末の中）にだけ保存され、どこにも送信されません。
  このリポジトリにも写真は含まれません。
- 「曲をえらぶ」で検索した言葉は、Apple の検索サービスに送られます。
- 「みんなでランキング」で遊ぶときだけ、名前・スコア・小さな顔写真（96px）が
  幹事のスプレッドシートに送られます。ほかの写真は端末から出ません。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面とスタイル |
| `game.js` | ゲーム本体 |
| `beat.js` | 曲の解析（テンポ検出と譜面の自動生成） |
| `server/code.gs` | みんなでランキングの受け口（Google Apps Script） |

`beat.js` は音の立ち上がり（スペクトルフラックス）を4つの帯域で調べ、
自己相関とくし形フィルタでテンポを推定したあと、最小二乗法で拍の格子を引き直します。
低い音は左のレーン、高い音は右のレーンに割り当てます。

内蔵ビートの音は WebAudio の合成音で作っていて、音源ファイルは使っていません。
