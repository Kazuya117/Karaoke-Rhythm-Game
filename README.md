# 顔ノーツ☆カラオケバトル

仲間の顔写真がノーツになって流れてくる、カラオケ向けのリズムゲームです。
スマホ1台を回して順番にプレイし、最後に顔写真つきで結果発表します。

## あそびかた

1. 「あそぶ」→ メンバーの名前と顔写真を登録（写真はなくてもOK）
2. モードをえらぶ
   - **内蔵ビート**：ゲームが演奏するオリジナル曲（3曲）で遊ぶ
   - **カラオケに合わせる**：カラオケ機で流れている曲のビートをタップしてテンポを測り、その曲に合わせて遊ぶ（歌う人の横でタンバリン係）
3. 流れてくる顔が下の丸に重なった瞬間に、そのレーンをタップ！
   - 10コンボでサングラス😎、25コンボで王冠👑、50コンボで虹色リング
   - ミスが続くと泣き顔に…
   - サビ（フィーバー）では全員の顔が流れてきます
4. 全員が終わったら結果発表

パソコンでは `D` `F` `J` `K` キーでも遊べます。

## 写真について

写真はブラウザの localStorage（その端末の中）にだけ保存され、サーバーには送信されません。
このリポジトリにも写真は含まれません。
